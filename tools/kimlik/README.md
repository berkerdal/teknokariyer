# tools/kimlik

TeknoKariyer kimlik dosyalarını üreten betikler. Ayrıntı: `docs/kimlik/README.md`.

- `uret.py`: logo, sembol ve favicon SVG'leri → `docs/kimlik/<alternatif>/`
- `sunum.py`: kimlik sunum sayfası ve `tokenlar.json` → `docs/kimlik/`
- `ana-logo.json`: ana Teknokent logosundan alınan vektör çizimler
- `fontlar/`: eğriye çevrilen yazı tipleri (SIL Open Font License 1.1, lisans dosyaları yanında)

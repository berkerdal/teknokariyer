# TeknoKariyer

Pamukkale Teknokent kariyer portalı.

- `CLAUDE.md`: proje bağlamı (kurum bilgileri, kurumsal kimlik, denetimden çıkan dersler, kararlar)
- `docs/denetim-raporu.pdf`: yeni web sitesi ve CMS denetim raporu (Kasım 2026)
- `docs/logo-teknokent.pdf`: kurumsal logo
- `docs/talimatlar.md`, `docs/ham-notlar.md`: ürün ve tasarım talimatları, kurumun ham notları
- `docs/kimlik/`: TeknoKariyer alt marka kimliği (onay bekliyor)
- `tools/kimlik/`: kimlik dosyalarını üreten betikler
